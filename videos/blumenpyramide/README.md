# Blumenpyramide — Herbstzauber

Publicité verticale de 30 secondes : huit scènes, textes allemands, bouquets d'automne et Halloween, musique originale.

- **Blumenpyramide-HD.mp4** : 1080 × 1920, 60 images/seconde, environ 49 Mo.
- **Blumenpyramide-leger.mp4** : 720 × 1280, 60 images/seconde, environ 4,8 Mo.

Pour télécharger une vidéo sur GitHub, ouvrir son fichier puis utiliser **Download raw file / Télécharger le fichier brut**. La connexion à GitHub est nécessaire si le dépôt est privé.

Master rendu avec HyperFrames et Theatre.js. Les bouquets sont des visuels générés pour ce concept publicitaire.
